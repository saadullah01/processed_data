This is calling a tiff library function:
    TIFFReadRGBAImageOriented()
to decode the compressed string in the tif into a raster image, which is written into tiffdata.

leptonica has no control over the compressed string, or the decoding functions in the tiff librrary.
If they find an uninitialized value when decoding, there is nothing that the leptonica wrapper can do about it.
